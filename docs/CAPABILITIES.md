# Матрица фактических возможностей

Дата актуализации: **2026-07-12**.

Статусы:

- ✅ production — доступно из Telegram-flow и покрыто тестами;
- 🟡 conditional — доступно только при проверяемых условиях;
- ⚪ optional — отдельный профиль зависимостей;
- ⛔ disabled — не реализовано или не валидировано.

| Возможность | Статус | Источник / метод | Поведение при отсутствии данных |
|---|---:|---|---|
| Несколько полей | ✅ | PostgreSQL `fields` / `crop_seasons` | поле не создаётся без валидных координат |
| Конкурентный onboarding | ✅ | PostgreSQL upsert + row lock | один пользователь и одно первичное поле |
| Персистентный FSM | ✅ | Redis | production не запускается без Redis |
| Callback idempotency | ✅ | Redis delivery/action leases | повтор не выполняет handler второй раз |
| Оперативная погода | ✅ | Open-Meteo Forecast API | явная ошибка без эвристической погоды |
| Сезонная история | 🟡 | Open-Meteo Historical Weather API, реанализ | отчёт деградирует до доступного окна |
| Provider provenance | 🟡 | model config, retrieval time, cache policy | неизвестные model run/resolution не выдумываются |
| ГДД | ✅ | daily-average method, crop `Tbase` | `None` при отсутствии завершённого ряда |
| Сезонная сумма ГДД | 🟡 | строго с локальной даты начала | не заявляется без строки на дату старта |
| Автоматическая фенофаза | ⛔ | пороги не валидированы | только наблюдение пользователя |
| ГТК Селянинова | 🟡 | завершённые сутки с `Tср > 10°C` | не рассчитывается при коротком/неполном окне |
| Осадки − ET₀ | 🟡 | парные завершённые значения | пропуски не превращаются в ноль |
| Frost screening | ✅ | прогнозная суточная Tmin воздуха 2 м | отдельный статус `insufficient_forecast_data` |
| Crop/phase damage model | ⛔ | требуется нормативная база | не генерируется |
| Ежедневные отчёты | ✅ | APScheduler + Redis lease | все enabled fields, локальное утреннее окно |
| Температурные алерты | ✅ | APScheduler + Redis lease | все enabled fields, dedup по field/event |
| RAG-поиск | ⚪ | ChromaDB + sentence-transformers | кнопка скрыта при `RAG_ENABLED=false` |
| LLM-ответ по RAG | ⚪ | OpenAI-compatible provider | отсутствие источника не подменяется генерацией |
| SoilGrids | ⛔ | provider adapter отсутствует | данные почвы не показываются |
| Sentinel/MODIS NDVI/LAI | ⛔ | provider отсутствует | спутниковые индексы не показываются |
| ERA5/CDS pipeline | ⛔ | job/cache contract отсутствует | климатическая норма не имитируется |
| SPI | ⛔ | нет длинного ряда и distribution fit | не рассчитывается |
| Прогноз урожайности | ⛔ | нет реальной выборки и валидации | отсутствует в UI/runtime |
| Дозы препаратов/удобрений | ⛔ | нет нормативного контекста | не генерируются |

## Инварианты данных

1. `reanalysis`, `operational_past` и `forecast` не смешиваются.
2. Текущий локальный день относится к прогнозу.
3. Строки до локальной даты посева не входят в ГДД.
4. Прогнозные осадки не входят в завершённый ГТК.
5. `NaN` не заменяется фиктивным нулём.
6. Отсутствие Tmin не интерпретируется как отсутствие заморозка.
7. Фаза пользователя маркируется как наблюдение.
8. Неактивное поле продолжает мониториться, если уведомление включено.
9. Любой fallback снижает заявленную полноту и отображается пользователю.
