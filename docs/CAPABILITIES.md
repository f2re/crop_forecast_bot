# Матрица фактических возможностей

Дата актуализации: **2026-07-10**.

Статусы:

- ✅ production — доступно из реального Telegram-сценария и покрыто тестами;
- 🟡 conditional — доступно только при выполнении проверяемых условий;
- ⚪ optional — отдельный профиль зависимостей и настройка администратора;
- ⛔ disabled — не реализовано либо не прошло научную валидацию.

| Возможность | Статус | Реальный источник / метод | Поведение при отсутствии данных |
|---|---:|---|---|
| Несколько полей | ✅ | PostgreSQL `fields` / `crop_seasons` | поле не создаётся без валидных координат |
| Персистентный FSM | ✅ | Redis | production не запускается без Redis |
| Оперативная погода | ✅ | Open-Meteo Forecast API | явная ошибка провайдера, без эвристической погоды |
| Сезонная история | 🟡 | Open-Meteo Historical Weather API, реанализ | отчёт деградирует до доступного окна и помечает ограничение |
| ГДД | ✅ | daily-average method, crop `Tbase` | `None` и пояснение при отсутствии завершённого ряда |
| Сезонная сумма ГДД | 🟡 | только при покрытии даты начала сезона | выводится сумма за доступный период |
| Автоматическая фенофаза | ⛔ | пороги не валидированы по регионам | используется только ручное наблюдение пользователя |
| ГТК Селянинова | 🟡 | завершённые сутки с `Tср > 10°C` | не рассчитывается при пропусках/коротком тёплом окне |
| Осадки − ET₀ | 🟡 | paired completed-day values, ET₀ провайдера | отсутствующие значения не превращаются в ноль |
| Frost screening | ✅ | прогнозная суточная Tmin воздуха 2 м | нет вероятности ущерба и нет фиктивного часа события |
| Crop/phase damage model | ⛔ | требуется нормативная база и валидация | не генерируется |
| Ежедневные отчёты | ✅ | APScheduler + Redis lease | дедупликация по пользователю, полю и локальной дате |
| Температурные алерты | ✅ | APScheduler + Redis lease | повтор не отправляется в TTL-окне |
| RAG-поиск | ⚪ | ChromaDB + sentence-transformers | кнопка скрыта при `RAG_ENABLED=false` |
| LLM-ответ по RAG | ⚪ | Groq/Together/OpenAI/Ollama через OpenAI-compatible API | сервис сообщает о недоступности, источники не выдумываются |
| SoilGrids | ⛔ | provider adapter отсутствует | данные почвы не показываются |
| Sentinel/MODIS NDVI/LAI | ⛔ | production provider отсутствует | спутниковые индексы не показываются |
| ERA5/CDS pipeline | ⛔ | job/cache/provider contract отсутствует | климатическая норма не имитируется |
| SPI | ⛔ | нет длинного однородного ряда и fit distribution | не рассчитывается |
| Прогноз урожайности | ⛔ | нет реальной обучающей выборки и независимой валидации | отсутствует в UI и runtime |
| Дозы препаратов/удобрений | ⛔ | нет нормативного источника и контекста | не генерируются |

## Инварианты данных

1. `reanalysis`, `operational_past` и `forecast` не смешиваются.
2. Текущий локальный день относится к прогнозной части, а не к завершённому прошлому.
3. Прогнозные осадки не входят в ГТК завершённого периода.
4. `NaN` не заменяется фиктивным нулём.
5. Фаза пользователя маркируется как наблюдение, а не модельный результат.
6. Любой fallback снижает заявленную полноту и отображается в отчёте.
