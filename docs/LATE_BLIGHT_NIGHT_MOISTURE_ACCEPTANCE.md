# Приёмка ночного контекста фитофтороза

Вертикальный срез принимается только при выполнении условий:

- Hutton остаётся единственным триггером предупреждения;
- большой перепад температуры при сухом воздухе не формирует период;
- точка росы, туман, видимость и осадки показываются только как пояснение;
- изменение поясняющих полей не создаёт новый delivery transition;
- расчёт доступен только для явно подтверждённого открытого грунта;
- теплица и неизвестный тип выращивания не попадают в scheduler;
- отсутствие дополнительных полей не подменяется нулём и не ломает Hutton;
- live-provider smoke проверяет фактические имена и полноту полей Open-Meteo;
- сообщения не содержат диагноза, вероятности заражения, препарата или дозы;
- Python 3.10/3.11, startup-smoke, PostgreSQL/Redis, Alembic и backup/restore зелёные.
