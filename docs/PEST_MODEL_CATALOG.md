# Каталог погодозависимых моделей вредителей

Дата проверки: **2026-08-03**.

## 1. Основной принцип

Культура связывается с вредителем только тогда, когда для конкретного вида найден воспроизводимый опубликованный метод, содержащий:

1. точный вид вредителя;
2. конкретную культуру или явно проверенную группу культур;
3. биологическую или календарную точку отсчёта;
4. используемый метеорологический показатель;
5. нижний и, при необходимости, верхний температурный порог;
6. способ вычисления градусо-суток;
7. накопления до наблюдаемых стадий или окон обследования;
8. регион и условия, в которых параметры получены;
9. первичный источник;
10. формулировку, не подменяющую обследование поля.

Факт, что насекомое питается культурой, недостаточен. Общие списки вредителей, энциклопедии и фотографии не создают погодозависимую модель.

## 2. Методическая база

Архитектура следует принципам комплексной защиты растений:

- правильное определение вида;
- обследование и количественный учёт;
- прогноз времени развития как помощь в выборе срока обследования;
- сопоставление с экономическим порогом вредоносности;
- отдельное решение о мерах защиты.

Базовые источники по методологии:

- Radcliffe E. B., Hutchison W. D., Cancelado R. E. *Integrated Pest Management: Concepts, Tactics, Strategies and Case Studies*. Cambridge University Press, 2008. DOI: `10.1017/CBO9780511626463`;
- Radcliffe's IPM World Textbook, University of Minnesota: `https://ipmworld.umn.edu/`;
- NEWA, Cornell IPM — обзор методов градусо-суток: `https://newa.cornell.edu/about-degree-days`;
- UC IPM Phenology Model Database: `https://ipm.ucanr.edu/weather/phenology-models-description/`;
- Wisconsin AgWeather Thermal Models: `https://agweather.cals.wisc.edu/thermal-models/degree-days`.

Из этих источников следует важное ограничение: одинаковая сумма температур, рассчитанная разными методами, может различаться. Поэтому в базе хранится не только порог, но и точный метод вычисления.

## 3. Допущенные модели

### 3.1. Картофель — колорадский жук

| Поле | Значение |
|---|---|
| Вид | *Leptinotarsa decemlineata* |
| Культура | картофель |
| Точка отсчёта | первая фактически найденная кладка яиц |
| Температура | Tmin и Tmax воздуха на высоте 2 м |
| Нижний порог | 11,1 °C |
| Метод | среднее суточных Tmin и Tmax |
| Назначение | окна повторного осмотра кладок и личинок |
| Основной источник | University of Wisconsin Vegetable Entomology |

Источник: `https://vegento.russell.wisc.edu/pests/colorado-potato-beetle/`

Модель не переносится на томат и другие паслёновые. Для рабочего каталога источник и сценарий наблюдения относятся к картофелю.

### 3.2. Кукуруза — совка ипсилон (чёрная совка)

| Поле | Значение |
|---|---|
| Вид | *Agrotis ipsilon* |
| Культура | кукуруза |
| Точка отсчёта | значимый улов: не менее 8 бабочек за две последовательные ночи |
| Температура | Tmin и Tmax воздуха на высоте 2 м |
| Нижний порог | 10,0 °C, то есть 50 °F |
| Метод | простая суточная сумма от средней температуры |
| Назначение | начало обследования до появления крупных подгрызающих личинок |
| Основной источник | University of Minnesota Extension |

Источник: `https://extension.umn.edu/corn-pest-management/black-cutworm-corn`

Опубликованные границы в градусо-сутках Фаренгейта преобразованы в градусо-сутки Цельсия делением на 1,8:

| F·сут | C·сут | Окно |
|---:|---:|---|
| 0–90 | 0–50,0 | яйцекладка и развитие яиц |
| 91–311 | 50,0–173,3 | личинки 1–3-го возрастов, питание листьями |
| 312–364 | 173,3–202,8 | 4-й возраст, начинается подгрызание |
| 365–430 | 202,8–239,4 | 5-й возраст, основное подгрызание |
| 431–640 | 239,4–356,1 | 6–7-й возрасты, подгрызание ослабевает |
| 641–989 | 356,1–549,4 | окукливание, питание прекращается |

Сам улов хорошо задаёт время развития, но источник предупреждает, что он может завышать риск повреждения поля. Поэтому бот никогда не пишет, что кукуруза заражена.

Модель пока не связана с соей, хотя вид может повреждать сою: для сои требуется отдельная проверка стадий культуры, симптомов и порогов решения.

### 3.3. Кукуруза и соя — ростковая муха по температуре почвы

| Поле | Значение |
|---|---|
| Вид | *Delia platura* |
| Культуры | кукуруза и соя |
| Точка отсчёта | 1 января текущего года |
| Температура | модельный слой почвы 0–7 см |
| Нижний порог | 3,9 °C |
| Верхний порог | 29,0 °C |
| Метод | одна синусоида, горизонтальное верхнее отсечение |
| Первое окно | 206 °C·сут — опубликованное 50%-ное весеннее появление взрослых мух по температуре почвы около 5,7 см |
| Основной источник | UC IPM Phenology Model Database |

Основные источники:

- `https://ipm.ucanr.edu/weather/phenology-models-description/seedcorn-maggot/`;
- `https://agweather.cals.wisc.edu/thermal-models/scm`;
- `https://extension.umn.edu/corn-pest-management/seedcorn-maggot`.

Ограничения:

- публикация использовала температуру почвы примерно на глубине 5,7 см;
- Open-Meteo предоставляет среднюю температуру модельного слоя 0–7 см;
- совпадение глубины приблизительное, а не точное;
- появление взрослых мух не означает повреждение конкретного поля;
- риск сильно зависит от свежей органики, обработки почвы, холодного прорастания и истории участка;
- модель используется только для окна обследования кукурузы и сои.

В лук модель не переносится. Для лука опубликован другой сценарий, где отсчёт ведут после обработки почвы или формирования гряд. Это отдельная модель и отдельная пользовательская точка отсчёта.

## 4. Методы вычисления

### 4.1. Простое суточное среднее

```text
Tср = (Tmax + Tmin) / 2
DD = max(0, Tср − Tниж)
```

Если источник задаёт верхний предел:

```text
Tср = min(Tср, Tверх)
```

Метод используется только для моделей, где он явно принят источником.

### 4.2. Одна синусоида с горизонтальным верхним отсечением

Между Tmin и Tmax строится одна условная суточная синусоида. Градусо-сутки равны площади температурной кривой выше нижнего порога. При горизонтальном верхнем отсечении площадь выше верхнего порога вычитается: развитие выше этого порога не ускоряется.

Этот метод нужен для ростковой мухи. Заменять его простым средним нельзя: при пересечении нижнего или верхнего порога результаты различаются.

## 5. Источники температуры почвы

### 5.1. Выбранный рабочий источник

#### Текущие и будущие сутки

Open-Meteo ECMWF API:

```text
endpoint: https://api.open-meteo.com/v1/ecmwf
variable: soil_temperature_0_to_7cm
model: ECMWF Best Match
точная выбранная сетка: endpoint не сообщает
```

Документация: `https://open-meteo.com/en/docs/ecmwf-api`

Живой договор API проверяется отдельным заданием GitHub Actions. На дату аудита рабочий endpoint принимает `soil_temperature_0_to_7cm`; автоматическая проверка нужна потому, что опубликованные названия переменных и фактический перечень endpoint могут изменяться независимо.

#### Историческая часть

Open-Meteo Historical Weather API:

```text
endpoint: https://archive-api.open-meteo.com/v1/archive
variable: soil_temperature_0_to_7cm
model: ERA5-Land
номинальная сетка: около 0,1° / 9–11 км
```

Документация: `https://open-meteo.com/en/docs/historical-weather-api`

Преимущества для слабого сервера:

- API-ключ не требуется;
- открытая лицензия с указанием источника;
- единый JSON-интерфейс;
- почасовые значения;
- исторический и прогнозный ряд;
- не нужны GRIB, xarray, cfgrib и локальное хранение массивов.

### 5.2. Почему не OpenWeather по умолчанию

OpenWeather предоставляет почвенные переменные в отдельных продуктах, но рабочие вызовы требуют API-ключа, а часть исторических и специализированных данных зависит от тарифного плана. Это ухудшает установку «из коробки» и создаёт ещё один секрет и договор провайдера.

OpenWeather можно добавить как необязательный резервный адаптер, но он не нужен для минимальной версии, пока Open-Meteo покрывает требуемый слой.

### 5.3. Другие рассмотренные источники

| Источник | Оценка |
|---|---|
| CDS ERA5-Land | научно полезен для однородного анализа; требует учётной записи, токена и отдельного загрузчика; не нужен для оперативного слабого сервера |
| Open-Meteo GFS | доступны слои 0–10 см и глубже; глубина не совпадает с моделью 5,7 см и отличается от ECMWF/ERA5-Land 0–7 см |
| ECMWF Open Data напрямую | качественный источник, но потребуются GRIB-декодирование, выбор сетки и более тяжёлый стек |
| SoilGrids | статические свойства почвы, а не оперативная температура |
| датчик пользователя | лучший локальный источник при правильной глубине и установке; требует отдельного ввода или интеграции |

## 6. Контроль качества температурного ряда

Реализация:

- агрегирует почасовую температуру по местной календарной дате;
- требует не менее 18 валидных часов в сутках;
- не заменяет пропуски нулём;
- не смешивает будущие сутки с уже накопленной суммой;
- отдаёт преимущество оперативному ряду при перекрытии с реанализом;
- хранит тип строки: реанализ, завершённое оперативное прошлое, текущий прогноз или прогноз;
- показывает источник, глубину и время получения; сетку показывает только тогда, когда провайдер её сообщает;
- ежегодно переводит календарную модель на новое 1 января и сбрасывает старые уведомления.

## 7. Аудит остальных культур проекта

| Культура или группа | Решение | Причина |
|---|---|---|
| картофель | колорадский жук — включён | есть точка отсчёта, температурный порог и окна личиночных возрастов |
| кукуруза | совка ипсилон и ростковая муха — включены | есть опубликованные модели и конкретные точки отсчёта |
| соя | ростковая муха — включена | сезонная почвенная модель прямо применяется к сое |
| лук и чеснок | не связано | найденная модель ростковой мухи использует обработку почвы как другую точку отсчёта; нужен отдельный сценарий |
| люцерна | не связано | модель люцернового долгоносика существует, но перед включением нужны проверка полного набора стадий, региона и метода |
| пшеница, ячмень, овёс, рожь, тритикале | не связано | не найден единый проверенный температурный профиль, пригодный для текущего каталога без ловушек и региональной сети |
| подсолнечник, рапс, лён, горчица | не связано | отдельные вредители имеют региональные прогнозы, но параметры не проходят текущий договор допуска |
| томат, огурец и бахчевые | не связано | общие календари вредителей не считаются погодозависимой моделью; теплица и открытый грунт требуют разных схем |
| сахарная и столовая свёкла, морковь | не связано | кормовая связь известна, но в рабочую базу не найден полный проверенный набор «вид — метод — точка отсчёта — стадии» |
| кормовые травы | не связано | нужны отдельные виды и региональная проверка, универсальная модель недопустима |

## 8. Следующие кандидаты

Порядок дальнейшего аудита:

1. люцерновый долгоносик на люцерне;
2. европейский кукурузный мотылёк на кукурузе;
3. луковая муха с точкой отсчёта по ловушке или обработке почвы;
4. отдельная модель болезни картофеля или томата с почасовой влажностью;
5. модели тепличных вредителей только после добавления микроклимата внутри сооружения.

Каждый кандидат проходит тот же договор допуска. До этого в Telegram он не показывается.
