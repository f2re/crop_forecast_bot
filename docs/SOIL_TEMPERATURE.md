# Температура почвы: источник и применение

## Что показывает `/soil`

Бот показывает температуру верхнего модельного слоя почвы **0–7 см** для координат активного поля:

- среднее, минимум и максимум за последние полные сутки;
- изменение за три полных суток;
- прогноз на семь суток.

Суточные значения рассчитываются из почасового ряда. Это не температура в одной точке и не измерение на глубине заделки семян.

## Откуда берутся данные

Оперативный экран `/soil` вызывает ECMWF Forecast API Open-Meteo:

```text
endpoint: /v1/ecmwf
variable: soil_temperature_0_to_7cm
past_days: 14
forecast_days: 7
timezone: auto
cell_selection: land
```

Запрос не фиксирует параметр `models`, поэтому Open-Meteo применяет конфигурацию **Best Match** из доступных моделей ECMWF. Доступные расчёты имеют шаг примерно 9–25 км, но ответ API не сообщает, какая конфигурация была выбрана для конкретного запроса. Поэтому бот не выводит вымышленный точный размер сетки.

Важное ограничение: строка за последние полные сутки относится к архиву недавних расчётов ECMWF, а не к наблюдению метеостанции. ERA5-Land подключается только для более длинного исторического периода, когда его явно запрашивает расчёт погодозависимой модели вредителя.

ECMWF обновляет расчёты до четырёх раз в сутки. Локальный кэш бота для оперативной температуры почвы действует не более одного часа.

Официальные источники:

- https://open-meteo.com/en/docs/ecmwf-api
- https://open-meteo.com/en/docs/historical-weather-api
- https://confluence.ecmwf.int/display/CKB/ERA5-Land%3A+data+documentation

## Насколько данным можно доверять

Это реальный результат численной модели ECMWF, а не случайная эвристика. Он пригоден для оценки общего прогрева и охлаждения верхнего слоя, сравнения дней и расчёта только тех погодозависимых моделей, для которых опубликован соответствующий температурный показатель.

Точное значение на поле может отличаться из-за:

- влажности и типа почвы;
- растительного покрова и пожнивных остатков;
- обработки почвы и орошения;
- склона, экспозиции и микрорельефа;
- фактической глубины измерения.

Для решения о посеве, обработке или защите растений требуется контрольный замер почвенным термометром на рабочей глубине в нескольких точках поля. Универсальный вывод «можно сеять» по одному модельному числу запрещён.

## Требования к сообщению Telegram

Основной экран должен быть коротким:

1. поле и слой;
2. последние полные сутки с пометкой «по модели»;
3. краткий тренд;
4. четыре ближайших дня и сводка оставшегося периода;
5. источник и местное время обновления;
6. одно предупреждение «модель, не датчик».

Подробности выводятся отдельной кнопкой **«Что это значит»**, а не повторяются в каждом отчёте.
