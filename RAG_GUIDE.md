# 📚 Руководство по RAG-модулю (База знаний)

RAG (Retrieval-Augmented Generation) позволяет боту отвечать на вопросы, основываясь на загруженной вами научной литературе, справочниках и регламентах.

## 1. Подготовка литературы

Поместите ваши документы в папку `data/literature/`. Поддерживаются форматы:
- **PDF** (с текстовым слоем)
- **TXT**
- **MD** (Markdown)

### Рекомендуемые источники:
- Справочники ФАО (FAO) по культурам.
- Региональные агроклиматические справочники.
- Методические указания по защите растений.
- ГОСТы в области агрометеорологии.

> **Важно:** Если у вас PDF-скан без текстового слоя, предварительно обработайте его через OCR (например, `ocrmypdf`).

## 2. Индексация базы знаний

Перед первым запуском или после добавления новых файлов необходимо обновить векторную базу данных ChromaDB.

```bash
# Простая индексация (добавляет только новые файлы)
python -m src.knowledge.indexer

# Полная переиндексация (удаляет старую базу и создает заново)
python -m src.knowledge.indexer --reset

# Просмотр статистики базы
python -m src.knowledge.indexer --info
```

## 3. Настройка LLM (Агросоветника)

Для того чтобы бот мог анализировать найденный текст и давать советы, необходимо настроить API одного из провайдеров в `.env`:

```env
# Выберите провайдера: groq (рекомендуется), together, openai или ollama
LLM_PROVIDER=groq
GROQ_API_KEY=gsk_your_key_here
```

### Рекомендация для MVP: **Groq**
- Бесплатный лимит (14,400 запросов/день).
- Модель: `llama-3.3-70b-versatile` (очень быстрая и умная).
- Регистрация: [console.groq.com](https://console.groq.com)

## 4. Как это работает для фермера

1. Пользователь нажимает кнопку **"🤖 Агросоветник"**.
2. Вводит вопрос (например: *"При каких температурах пшеница уходит в кущение?"*).
3. Бот:
   - Ищет релевантные фрагменты в `data/literature/`.
   - Получает текущие агроиндексы поля пользователя (ГТК, ГДД, влага).
   - Формирует запрос к LLM.
   - Выдает краткий ответ со ссылкой на источники.

## 5. Качество поиска

Текущая модель эмбеддингов: `paraphrase-multilingual-MiniLM-L12-v2`. Она хорошо работает с русским языком и не требует GPU. Если вам нужно более высокое качество для специфических агро-терминов, в `src/knowledge/rag_engine.py` можно заменить модель на `deepvk/USER-bge-m3`.
